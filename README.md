# Healthcare-Analytics-Dashboard-

## Aim / Objective of the Project:
The aim of this project is to transform raw hospital data into actionable insights that help healthcare administrators:
This project presents an interactive Excel dashboard built to monitor and analyze hospital performance across 55,500 patient records from 2019 to 2024.

## Data set used
- <a href="https://github.com/Aronne-james/Healthcare-Analytics-Dashboard-/blob/main/yhe%20project.xlsx">Dataset view</a>

The dataset contains 15 fields including patient demographics, medical conditions, medications, admission types, insurance providers, doctors, hospitals, billing amounts, and length of stay.
