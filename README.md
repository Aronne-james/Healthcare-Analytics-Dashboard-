# Healthcare-Analytics-Dashboard-

## Aim / Objective of the Project:
The aim of this project is to transform raw hospital data into actionable insights that help healthcare administrators:
This project presents an interactive Excel dashboard built to monitor and analyze hospital performance across 55,500 patient records from 2019 to 2024.

## Data set used
- dataset <a href="https://github.com/Aronne-james/Healthcare-Analytics-Dashboard-/blob/main/yhe%20project.xlsx">Dataset view</a>

The dataset contains 15 fields including patient demographics, medical conditions, medications, admission types, insurance providers, doctors, hospitals, billing amounts, and length of stay.

- dashboard <a href="https://github.com/Aronne-james/Healthcare-Analytics-Dashboard-/blob/main/hospital%20image%20new.png">dashboard view</a>

Tools Used:* Microsoft Excel - Data Cleaning, PivotTables, PivotCharts, Slicers, KPI Cards, Dashboard Design

This project presents an interactive Excel dashboard built to monitor and analyze hospital performance across 55,500 patient records from 2019 to 2024.
1. To track overall patient volume, total treatment cost, and average length of stay.
2. To identify high-risk demographics and prevalent medical conditions driving hospital admissions.
3. To analyze revenue dependency on major insurance providers and evaluate cost efficiency.
4. To assess hospital operations, doctor workload, and admission type distribution.
5. To provide data-driven recommendations for reducing length of stay, optimizing pharmacy inventory, and improving geriatric care management.

*Key Insights:*
- Elderly patients (61+) represent the largest patient segment with chronic conditions.
- Two insurance providers account for 40% of total patient coverage.
- Average length of stay remains high, indicating an opportunity for operational cost optimization.
